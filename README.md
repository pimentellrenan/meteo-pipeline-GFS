# Meteo Pipeline GFS

Pipeline de processamento de dados meteorológicos do modelo GFS (Global Forecast System).

## Descrição

Este projeto implementa um pipeline automatizado para ingerir, processar e armazenar dados de previsão meteorológica obtidos do modelo GFS da NOAA.

## Recursos

- Ingestão de dados GFS
- Processamento e validação de dados meteorológicos
- Armazenamento estruturado de previsões
- Análises e consultas climatológicas

## Pré-requisitos

- Python 3.8+
- Docker (opcional)
- Git

## Instalação

1. Clone o repositório:
```bash
git clone https://github.com/pimentellrenan/meteo-pipeline-GFS
cd meteo-pipeline-GFS
```

2. Instale as dependências:
```bash
pip install -r requirements.txt
```
